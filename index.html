Works with youtube.com/channel/UC… and youtubekids.com/channel/UC… links, and raw channel IDs. @handle links (like youtube.com/@Bluey) need a YouTube API key (set it in Options) — or find the ID on the channel page: …more → Share channel → Copy channel ID.
Approved single videos are mixed into the feed of their category, no matter which channel they come from.
Optional but recommended. With a key, KidTube shows a real thumbnail grid of each channel's videos, channel avatars, and understands @handle links. Without a key, clicking a channel opens its upload playlist inside the YouTube player.
Free key: console.cloud.google.com → create project → APIs & Services → Library → YouTube Data API v3 → Enable → Credentials → Create credentials → API key.
New uploads are picked up automatically about once an hour; press Refresh to check right away. Shorts are never shown — only regular videos.
The kid sees a bar with the time left. When it runs out, the current video may finish, then KidTube says good night until a parent adds time.
Settings are stored in this browser only. Copy them to move KidTube to another computer or browser.
